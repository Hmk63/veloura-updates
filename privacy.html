أين تُحفظ البيانات

كل بيانات العيادة (المرضى، المواعيد، العلاجات، الحسابات، الصور والمرفقات) تُحفظ في قاعدة بيانات على حاسوب العيادة نفسه. المطوّر لا يستلم هذه البيانات ولا يطّلع عليها، والبرنامج لا يحتوي أدوات تتبّع أو إحصاءات استخدام.

حساب Google (اختياري)

إذا ربطت العيادة حساب Google، يطلب البرنامج صلاحية drive.file فقط، ليرفع ملفات النسخ الاحتياطي التي ينشئها إلى مجلد في Google Drive الخاص بالعيادة، ويحذف النسخ القديمة التي رفعها بنفسه. هذه الصلاحية لا تسمح للبرنامج برؤية أي ملف آخر في Drive. رمز الدخول يُحفظ على حاسوب العيادة فقط، ويمكن إلغاء الربط في أي وقت من شاشة النسخ الاحتياطي أو من إعدادات حساب Google.

استعمال البرنامج للمعلومات المستلمة من واجهات Google يلتزم بـ سياسة بيانات مستخدمي خدمات Google API، بما فيها متطلبات الاستخدام المحدود.

الاتصالات الأخرى

  • فحص التحديثات: يقرأ البرنامج ملف الإصدارات من GitHub، ولا يُرسل معه أي بيانات عن العيادة أو المرضى.
  • واتساب: أزرار الإرسال تفتح واتساب برسالة جاهزة، والمستخدم هو من يقرّر إرسالها.
  • تطبيق الهاتف: يتصل بحاسوب العيادة عبر الشبكة المحلية فقط، بعد الاقتران برمز من الإعدادات.

المسؤولية عن البيانات

العيادة هي صاحبة بيانات مرضاها والمسؤولة عنها، بما في ذلك حماية الحاسوب وكلمات المرور والنسخ الاحتياطية.

Privacy Policy

Last updated: 4 November 2026

Where data is stored

All clinic data (patients, appointments, treatments, accounts, photos and attachments) is stored in a database on the clinic's own computer. The developer does not receive or access this data, and the software contains no tracking or usage analytics.

Google account (optional)

If a clinic connects a Google account, the software requests only the drive.file scope, to upload the backup files it creates to a folder in the clinic's own Google Drive and remove older copies it uploaded itself. This scope does not let the software see any other file in Drive. The access token is stored only on the clinic's computer, and the connection can be removed at any time from the backup screen or from Google account settings.

Veloura Clinics System's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other connections

  • Update check: the software reads a release file from GitHub and sends no clinic or patient data with it.
  • WhatsApp: send buttons open WhatsApp with a prepared message; the user decides whether to send it.
  • Phone app: connects to the clinic computer over the local network only, after pairing with a code from Settings.

Responsibility

The clinic owns and is responsible for its patients' data, including securing its computer, passwords and backups.
